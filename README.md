# FlipLens AI
AI-powered marketplace valuation platform.

## 🚀 Features
- FastAPI backend
- AI product normalization
- Marketplace valuation engine
- Profit & ROI calculation
- Future support for:
  - Facebook Marketplace
  - eBay
  - Gumtree
  - Vinted

## Project structure
```
backend/   FastAPI API
frontend/  Next.js application
docs/      Documentation
```

## Tech Stack
### Backend
- FastAPI
- Pydantic
- Python

### Frontend
- Next.js
- TypeScript
- TailwindCSS
